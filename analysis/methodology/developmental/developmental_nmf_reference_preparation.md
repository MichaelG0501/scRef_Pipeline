# Developmental NMF reference preparation

The workflow reads original source files directly from /rds/general/project/tumourheterogeneity1/live/EAC_Ref_all/00_merged/developmental (override SCREF_DEVELOPMENTAL_SOURCE) and creates one non-integrated Seurat RNA object per study in the user-requested Developmental bundle. It preserves every source cell and metadata column; it does not select epithelial cells, fit NMF, integrate studies or infer trajectories. Existing input files remain unchanged. All seven prepared references are written directly as <study>.rds in the Developmental root. Source copies and exported cell/gene metadata remain under Original_data/. The bundle contains data only: documentation, summaries and audit reports are kept in project reports or the ignored session archive outside Developmental/. Outputs are explicitly requested under /rds/general/user/el1224/home/OAC_data/Developmental; the summary is also retained under scRef's live developmental reports.

Yu H5AD CSR counts are read as a transposed CSC matrix without changing values or cell order. Xu and Ding counts are read from MatrixMarket; Cao uses the stomach count RDS. Zhao and Tsubosaka use source RNA counts directly, avoiding obsolete Seurat accessors. Count-like inputs undergo Seurat LogNormalize with scale factor 10,000. Tsubosaka fractional values are retained without rounding and retain their processed-count provenance. The Nowicki-Osuch/Zhuang source logcounts assay is retained unchanged as RNA data; no artificial raw counts are generated and original-transform provenance remains an explicit comparability caveat. Supplied finite nonnegative logcounts can be factorized directly; they are not normalized again or labelled raw counts.

Gene symbols are used where supplied. Unmapped symbols retain their source gene IDs, explicitly flagged in the mapping. Underscores are changed to hyphens to match Seurat naming. Duplicate symbols in count-like inputs are summed before normalization. Duplicate processed/log-expression symbols stop execution because summing transformed values is not justified. No gene or cell QC threshold is imposed at this conversion stage; selection and QC belong to the later analysis. The output RNA data layer is finite and nonnegative; no scaled data, integration or batch correction is generated.

Original metadata columns are retained. source_orig_ident preserves any prior orig.ident; the new orig.ident combines the study with the explicitly mapped sample unit. Yu uses Sample/donor_id; Xu uses sample/embryo; Ding uses biosample_id/donor_id; Tsubosaka uses original orig.ident/patient; Nowicki-Osuch uses Sample/Patient. Cao uses Fetus_id as a donor-level stomach unit because its sample field denotes individual cells. Zhao is assigned one pooled_atlas analysis unit: its original orig.ident is constant and SID includes stage labels such as E6. Donor IDs remain unknown. This unit permits exploratory NMF and rank/seed stability checks, but does not establish replication across independent donors. Original source fields are retained for later curation. No sample identity is inferred by trimming barcodes.

Age labels are retained verbatim. Numeric Yu Age_week and Cao Development_day are copied into explicitly source-labelled fields. Missing numerical ages remain NA. Adult labels reflect study designation, not imputed participant ages. Carnegie stages and embryogenesis labels are not converted to numerical weeks. Exact regional assignments and healthy-versus-disease selections remain source-specific tasks.

Validation checks cell-ID uniqueness and expression/metadata alignment, finite nonnegative RNA data, dimensions, required metadata fields and preparation version. The summary records sample units, donors and readiness restrictions. SCREF_FORCE_REBUILD=TRUE authorizes replacement of the derived objects. Cache reuse reads and validates existing same-version objects; originals are never overwritten. RDS serialization is uncompressed to avoid long compression overhead on the large matrices. These objects can occupy substantially more disk space than source compressed files.

For downstream discovery, fit NMF independently within donor/sample epithelial compartments across multiple ranks, then derive reproducible consensus programs. Broad epithelial discovery can be complemented by within-lineage analysis. Early embryogenesis is a separate comparison and small foregut/stomach reference populations may support mapping only. Known ages, study-held-out replication and preservation of lineage markers are necessary for evaluating any integrated trajectory. A cross-atlas pseudotime does not establish lineage ancestry or resolve age-study confounding.

The Nowicki-Osuch/Zhuang object lacks expression column barcode names. Its original colData row identifiers are used explicitly for cell alignment and recorded in cell_id_basis; these internal identifiers must not be interpreted as sequencing barcodes. Patient and Sample fields remain the biological provenance.

The Yu source H5AD and download provenance are also stored in EAC_Ref_all/00_merged/developmental/raw_data/yu_2021. Yu metadata are decoded directly from the H5AD categorical/dataset fields; Cao metadata are read directly from df_cell.RDS and aligned using its cell-ID sample field. The workflow therefore does not depend on pre-exported bundle metadata or session scripts. EAC_Ref_all contains the available source files for all seven datasets; Tsubosaka and Nowicki remain processed sources, and this must not be described as having all untouched raw-count matrices.
