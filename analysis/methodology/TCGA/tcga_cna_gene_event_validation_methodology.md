# Targeted OAC gene CNA and MP validation

## Purpose and source gate

`analysis/TCGA/Auto_tcga_cna_gene_event_validation.R` extends the established TCGA CNA comparison without replacing its existing outputs. Its canonical root is `ref_outs/TCGA/cna_gene_event_validation/` inside the live project. The extension compares recurrent OAC gene loci and MP activity, and selects arm/MP and gene/MP pairs under the user's explicitly approved common rule.

Before association fitting, `Auto_tcga_cna_gene_event_preflight.R` verifies the source chain: `InferCNA.R` calls `infercna::infercna` and writes `ref_outs/by_samples/<sample>/<sample>_outs.rds`; `analysis/cnv/cnv_malignant_subclone_mp_heatmap.R` infers and merges CNA subclones from those matrices; `analysis/cnv/cna_subclone_expression_correlation.R` aggregates their arm profiles. These are the manual InferCNA subclones, not Numbat clone calls. The preflight recomputes every cached arm mean for all subclones in one complete sample directly from its original InferCNA matrix and requires an absolute discrepancy below `1e-10`. All 24,787 assigned cells are checked against canonical `orig.ident`. The main analysis additionally verifies the cell count of every one of the 112 cached subclones against the manual assignment table across 58 samples. Neither script reads a Numbat output.

The preflight uses the same whitespace-delimited GENCODE parser as the original producer; the external gene-order file contains trailing tabs on some lines. This avoids silently truncating the audit's gene universe. The required external reference is `/rds/general/project/spatialtranscriptomics/live/ITH_all/all_samples/hg38_gencode_v27.txt`. The complete source evidence is persisted in `reports/Auto_manual_infercna_provenance.csv`, `reports/Auto_input_inventory.txt`, and preflight run logs. A failed source gate stops downstream association fitting.

## Gene-level availability and source choice

The live cBioPortal catalogue for the same `esca_tcga_gdc` study confirms a `COPY_NUMBER_ALTERATION`, `DISCRETE` profile named `esca_tcga_gdc_cna`. It contains gene-level GISTIC 2.0 calls: `-2` deep/homozygous deletion, `-1` loss, `0` neutral, `1` gain and `2` amplification. These are DNA-based gene copy-number estimates, not RNA expression or isolated single-gene measurements independent of their surrounding segments. Adjacent genes may share the same altered segment.

The selected profile metadata are pinned at `intermediate/Auto_cbio_molecular_profiles.rds` and exported to `tables/Auto_cbio_molecular_profiles.csv`. The main analysis uses the generic molecular-data endpoint to retrieve explicit numeric calls, including observed zeros. It saves raw gene metadata, CNA sample identifiers and the complete response under `intermediate/source_data/`. Missing measurements are never converted to neutral calls. Invalid response schemas, values outside `-2:2`, missing selected gene mappings or duplicated gene/sample keys stop the run. Network errors stop after retries of the same request; they are not treated as evidence that gene-level data do not exist.

The user's conditional arm-only alternative is unnecessary because a true gene-level profile is available. The script therefore requires this exact gene profile and never silently switches to arm values. Official API source: `https://www.cbioportal.org/api/studies/esca_tcga_gdc/molecular-profiles`. Call semantics are documented at `https://docs.cbioportal.org/file-formats/` and `https://docs.cbioportal.org/user-guide/faq/`.

## Recurrence-ranked gene selection

The selected universe is exactly ten gain genes and ten loss genes, as explicitly confirmed by the user. The input catalogue is the parent workflow's complete reparse of `analysis/TCGA/OAC_CNV.xlsx`, stored at `ref_outs/TCGA/cna_recurrent_event_validation/tables/Auto_oac_cnv_curated_reparsed.csv`. Genes are ordered separately by the workbook's explicit `rank`, then original Excel row, retaining the original order of genes listed within a row. This follows the workbook ranking rather than attempting to reinterpret approximate frequency strings, some of which Excel stored as date-like numbers.

Aliases are normalized before deduplication: HER2 to ERBB2; P16/P14ARF to CDKN2A; PARK2 to PRKN; RASSF1A to RASSF1. A gene counts once per direction. The script then takes ten unique genes from each ordered list. The exact choice, recurrence ranks, original frequency strings, cytobands and source rows are retained in `tables/Auto_selected_oac_genes.csv`. Unmeasured RNA genes remain in the selected universe and are explicitly marked unavailable; they are not replaced with lower-ranked genes.

All MP work uses the exact current centred refined 17-MP gene collection, with MP2x, MP11c and MP18a excluded. The shared grouping CSV must match the five-state contract. This extension tests MPs only and does not redefine biological or technical states.

## Measurements and statistical units

For arm comparisons, scATLAS measurements are the existing per-subclone manual InferCNA arm means and corresponding mean MP activity from the validated parent cache. TCGA measurements are the parent length-weighted segment arm means and current bulk GSVA MP scores. The TCGA analysis restricts to primary EAC with RNA and segment overlap; no new threshold fitting occurs. TCGA sample barcodes are joined by their documented first 15 TCGA characters only. scATLAS sample identity is always `orig.ident` and is never inferred from barcodes.

For gene comparisons, the two platforms intentionally measure different predictors:

- **scATLAS:** RNA expression of the selected gene, averaged within each manual InferCNA subclone; this is not a gene-level CN estimate.
- **TCGA:** the gene's actual GISTIC copy-number call versus its bulk GSVA MP score.

The scATLAS RNA source is exclusively `ref_outs/by_samples/<orig.ident>/<orig.ident>_epi.rds`, which exists for all 58 source samples. The script reads the RNA `counts` layer, checks the assigned cells and their `orig.ident`, computes `log1p(10000 * counts / total_RNA_counts_per_cell)`, then averages those values per subclone. Library-size normalization uses all measured RNA genes. A measured zero is retained as zero; a gene absent from a sample's RNA feature universe remains unmeasured (`NA`). There is no replacement with another assay, layer or file. Processed per-subclone expression and cell counts remain live in `intermediate/Auto_sc_manual_subclone_gene_expression.rds`, with measurement coverage in `tables/Auto_gene_measurement_coverage.csv`.

The primary scATLAS unit is a subclone; the TCGA unit is a primary tumour sample. Gene copy-number calls are ordinal and are analyzed using rank correlation rather than being interpreted as continuous absolute copy numbers. Increasing values always mean increasing gene RNA or copy-number signal. A loss-gene label denotes the catalogue's recurrent event direction; the corresponding correlation is not sign-flipped.

## Tests, correction and pair selection

Spearman tests require at least five finite pairs and variation in both variables. Tests use `exact=FALSE` to handle tied ordinal CNA calls consistently. Undefined tests retain missing statistics; unexpected errors stop. BH FDR is calculated over the complete 46-arm by 17-MP family separately in each dataset and over the complete 20-gene by 17-MP family separately in each dataset. No correction is recalculated after selecting a figure subset.

The latest user instruction requires finite tests and the same nonzero rho sign in both datasets. No FDR, nominal-P or absolute-rho threshold gates pair selection. Among these concordant candidates, calculate the ascending rank of the maximum nominal P across datasets and the descending rank of the minimum absolute rho across datasets. Prioritize pairs with BH FDR below 0.05 in both datasets, then in either dataset, then those without FDR support. Within each significance tier, add the significance and strength ranks with equal weight; smaller scores rank first. This prioritization retains evidence that is strong in one assay without claiming that it is significant in both. Ties use maximum P, decreasing minimum absolute rho, minimum P, feature name and canonical MP order. Rank ties use the minimum rank. This rewards both significance and effect strength supported in both datasets rather than allowing one cohort to dominate. Select the first ten eligible arm/MP and gene/MP pairs; if fewer exist, plot all eligible pairs without admitting opposite directions. Complete ranks, component scores, rho, P and FDR remain exported.

To expose the nested structure, a separate sensitivity analysis averages subclone RNA/CNA and MP values to the sample level using subclone cell counts as weights, then repeats Spearman testing with BH correction within the arm and gene families. These sensitivity statistics are not silently substituted for the primary subclone analysis or used to alter the agreed selection rule.

## Interpretation and validation

Subclones from the same tumour are not independent patients. Primary subclone P values can overstate evidence when within-sample dependence is strong; sample-level sensitivity is supplied for this reason. These analyses are unadjusted for purity, sex, study, stage or other covariates. Direction stars and rank selection do not imply corrected significance. Selection favors strong observed associations and is exploratory, not held-out validation. RNA-versus-MP and CNA-versus-MP agreement concerns different predictors and does not prove a shared causal mechanism. MP-gene expression coupling and broad alterations shared by adjacent genes must be considered.

Validation requires a successful manual-source audit, explicit observed GISTIC neutral calls, valid unique gene/sample observations, exact MP and gene universes, full-family correction, unique test rows and the approved pair-selection rule. A separate PBS validation checks cached replot portability, all required files, PDF page counts and text bounds, and renders previews. A successful scheduler exit alone is not sufficient to adopt outputs.


The production validator is `temp/Auto_tcga_gene_event_output_validation.sh`. Its pinned PyMuPDF 1.26.7 import is stored canonically in `intermediate/source_data/software/pymupdf_1.26.7/`, copied once through PBS from the installed project package at `ref_outs/clinical_selected_survival/source_data/software/pymupdf_1.26.7/`. This avoids depending on a compatibility symlink in another workflow. Validation outputs include `reports/Auto_output_inventory.csv`, `reports/Auto_independent_validation.txt`, `reports/Auto_pdf_validation.csv` and page preview PNGs. The raw RNA check independently reproduces mean MYC expression in one manually assigned subclone to tolerance `1e-12`.
