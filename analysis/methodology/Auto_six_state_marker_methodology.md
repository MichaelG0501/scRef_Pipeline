# Auto Six-State Marker Workflow

Generated: 2026-04-08 19:36:32 BST

## Goal

Derive robust marker genes for the six finalized epithelial states defined in `ref_outs/Auto_final_states.rds`, explicitly excluding `Unresolved` and `Hybrid` cells.

## Inputs

- `ref_outs/EAC_Ref_epi.rds`: epithelial Seurat object.
- `ref_outs/Auto_final_states.rds`: finalized cell-state labels generated by the unresolved-relabel workflow.

## Finalized states retained

- `Classic Proliferative`
- `Basal to Intestinal Metaplasia`
- `Stress-adaptive`
- `SMG-like Metaplasia`
- `Immune Infiltrating`
- `3CA_EMT_and_Protein_maturation`

## Workflow summary

1. Subset the epithelial reference to the six finalized states only.
2. Re-run a six-state embedding with `NormalizeData`, `FindVariableFeatures` (3000 genes), `ScaleData`, `RunPCA` (30 PCs), `FindNeighbors`, `FindClusters` (resolution 0.5), and `RunUMAP`.
3. Run a pooled descriptive state-enrichment screen across all six states to define a generous candidate pool per state.
4. Re-test those candidate genes within each sample, comparing one state against the other five states from the same sample only.
5. Aggregate per-sample results across samples and studies, then keep only markers that are both recurrent and state-specific.
6. Plot the final marker set as a state-level heatmap using median sample-level expression per state.

## Why this method

A single pooled DGE analysis can be dominated by large samples or single studies. The implemented workflow is more robust because it requires a gene to reproduce within many independent samples before it is accepted as a final marker. This directly matches the requested emphasis on both specificity and sensitivity across samples and studies.

## Candidate screen

- The pooled screen is descriptive rather than inferential: for each state, genes are ranked by higher mean normalized expression in that state than in the remaining five states, together with higher detection frequency.
- Candidate retention thresholds: pooled `mean_state - mean_other >= 0.1`, pooled `pct_state >= 0.1`, and pooled `pct_state - pct_other >= 0.05`.
- Candidate pool cap: top 1500 genes per state after ranking by pooled mean-difference and pooled detection contrast.

## Per-sample DGE

- Test: Seurat `FindMarkers`, Wilcoxon rank-sum, one state versus the other five states within the same sample.
- A sample-state comparison is only run when the state has at least 20 cells and the in-sample background has at least 20 cells.
- A sample-level hit requires `FDR < 0.05`, `avg_log2FC >= 0.25`, `pct_state >= 0.25`, and `pct_state - pct_other >= 0.1`.

## Final marker rules

- Sample recurrence threshold: `max(8, ceiling(0.2 x eligible_sample_n))`.
- Study recurrence threshold: `max(2, ceiling(0.35 x eligible_study_n))`.
- Final pooled descriptive thresholds: `mean_state - mean_other >= 0.1`, `pct_state >= 0.25`, and `pct_state - pct_other >= 0.1`.
- Final recurrent thresholds: median sample-level `avg_log2FC >= 0.25`, median sample-level `pct_state >= 0.25`, median sample-level `pct_state - pct_other >= 0.1`.
- Final specificity rule: for a retained gene, the target state must have the highest median sample-level expression among all six states, and that expression must exceed the highest off-state median expression (`specificity_gap > 0`).

## Heatmap construction

- For each retained heatmap gene, expression was summarized as the median of per-sample average normalized expression values within each state.
- Rows were then z-scored across the six states to emphasize state preference rather than absolute abundance.
- The heatmap uses the top 15 final markers per state ranked by recurrence, effect size, and specificity.

## Notes

- This workflow intentionally prioritizes reproducibility across independent samples over maximizing the total number of retained genes.
- If a future iteration needs even stricter sample-level inference, the natural extension would be a pseudobulk or mixed-model framework, but for this task the recurrence-filtered within-sample DGE directly addresses the requested design.
