# Cell-State Workflow Methodology

This document describes the current epithelial state workflow implemented under `analysis/cell_states/`.

## Current State Decision

The selected state definition is Approach B without cell-cycle regression (`noreg`). The primary output is:

- `ref_outs/Auto_topmp_v2_noreg_states_B.rds`

The preferred final downstream state vector is:

- `ref_outs/Auto_final_states.rds`

`Auto_final_states.rds` is generated by relabeling unresolved Approach-B cells with retained 3CA pan-cancer metaprograms and then saving the merged vector for downstream scripts.

## `state_definition_approach_b_reg_noreg.R`

This script computes both `reg` and `noreg` versions for comparison, but downstream analyses should use the `noreg` outputs.

Operational steps:

1. Load `EAC_Ref_epi.rds`, filtered nMP19 UCell scores, MP gene metadata, `meta_full_epi.rds`, and cell-cycle genes.
2. Remove MPs with silhouette below zero.
3. Define cell-cycle MPs as `MP1`, `MP7`, and `MP9`.
4. Define biological state groups from non-cell-cycle MPs:
   - `Classic Proliferative`: `MP2`
   - `Basal to Intestinal Metaplasia`: `MP17`, `MP14`, `MP5`, `MP10`, `MP8`
   - `SMG-like Metaplasia`: `MP18`, `MP16`
   - `Stress-adaptive`: `MP13`, `MP12`
   - `Immune Infiltrating`: `MP15`
5. For `reg`, residualize non-cell-cycle MP scores against cell-cycle MP scores.
6. For `noreg`, keep non-cell-cycle scores without cell-cycle residualization.
7. Z-normalize by centering within sample and scaling by within-study standard deviation.
8. Assign cells to the strongest state-group score.
9. Label low-confidence cells as `Unresolved` and multi-state cells as `Hybrid` according to the script thresholds.
10. Write paired RDS outputs and comparison figures.

## `final_state_unresolved_relabel.R`

This script creates the preferred final state vector.

Operational steps:

1. Load Approach-B noreg states and noreg MP scores.
2. Load 3CA pan-cancer UCell scores.
3. Identify cells labeled `Unresolved` in the noreg Approach-B vector.
4. Assign unresolved cells to high-confidence retained 3CA MPs based on coverage across samples and studies.
5. Preserve the primary Approach-B states and technical labels where appropriate.
6. Save:
   - `ref_outs/task4_unresolved_states/Auto_task4_unresolved_relabel_states.rds`
   - `ref_outs/Auto_final_states.rds`
7. Regenerate final proportions, heatmaps, cell-cycle checks, and TCGA volcano outputs.

## Terminal State Figures

`state_mp_sample_abundance.R`, `final_state_overall_proportions.R`, `top_diverse_sample_state_umap.R`, `basal_smg_mp_signature_heatmap.R`, and `final_state_marker_discovery.R` should read `Auto_final_states.rds` when available. If they need to compare pre-final labels, they must make that explicit in the header and output names.

## Pseudotime And Hybrid Analyses

Pseudotime scripts use Monocle3 on sample-level subsets. Heavy scripts should save per-sample pseudotime vectors, fitted objects, projection tables, and state-distance matrices under an `intermediate/` or clearly named cache folder so plots can be regenerated without rerunning Monocle.

Hybrid scripts should use pairwise hybrid labels derived from top state-group scores. Multi-class hybrid concepts from older scripts are legacy and should not drive downstream analyses.

## Legacy Scripts

The `legacy_*` scripts in this folder document older/manual/clustered/top-MP alternatives. They are retained for comparison only and should not produce files that are consumed by new downstream analyses.
