# GSE207526 / Krish clinical validation workflow

## Scope and cohort assignment

The maintained workflow comprises the two download/preparation Python scripts and four R scripts in `analysis/GSE_Krish/`. The canonical result root is `ref_outs/GSE_Krish/`. Source records remain under `reference/`; replot and downstream objects are under `intermediate/`; source tables, statistics and manifests are under `tables/`; the selected figure set is under `figures/Auto_final/`; scientific reports and the linked current index are under `reports/`. Scheduler stdout/stderr remain directly in the project root. Matching local launchers mirror the script basenames under `job_scripts/GSE_Krish/` and use dmtcp.

GSE207526 contains 110 esophageal adenocarcinoma biopsies and ten healthy squamous specimens. The original processed matrix and GEO SOFT file are retained byte-for-byte. Only the 110 tumour IDs matching the supplied clinical file enter deconvolution or downstream analysis. The ten normal specimens remain identifiable in the source file and exclusion table; they never enter the GSE mixture matrix. The blank gene-symbol row is excluded explicitly and recorded. All remaining symbols are unique; negative, nonfinite or noninteger input counts stop the analysis. No TPM/FPKM substitution or alternate reference is permitted.

The original clinical file is `analysis/GSE_Krish/GSE207526_GSE112926_meta.txt`, moved from `analysis/clinical/` under the user's reorganization instruction. Its reference copy is unchanged. Literal `sample ` prefixes are removed from GEO titles; all other ID matching is exact. Rows represent one clinical sample/patient ID each. Sex, five-year age-at-diagnosis bands, Mandard grade, OS duration/status and detailed baseline AJCC stage come directly from that file. Exact age, the AJCC edition, and the OS time origin are not supplied and are not invented.

At the user's explicit instruction, observed Mandard defines **Neoadjuvant** (68), and missing Mandard defines **Surgery only** (42). These are operational proxy groups, not independently documented treatment histories. Actual modality (chemotherapy versus chemoradiotherapy), actual surgery receipt, and the treatment of patients with missing grades remain unverified. The label Neoadjuvant does not assert chemotherapy alone. GEO records describe pretreatment biopsy collection. No exposure-dependent survival origin or landmark is inferred. This group definition can introduce treatment misclassification and survivor/selection bias; all associations are exploratory and noncausal.

The redundant GSE112926 source matrix and SOFT file were removed under the user's explicit authorization, and are no longer downloaded, required or analysed. It shares 47 clinical IDs with the 110-case dataset and has four additional IDs without supplied clinical metadata; no claim is made that its 51 samples are an exact subset. Previous matching reports are retained only in the ignored session archive, never as current downstream inputs.

## Run order and resources

1. `geo_oac_bulk_download.py`: validate/reuse pinned original GSE207526 downloads and the original clinical-file copy, and retain the associated article XML. HTTPS downloads use curl with a bounded connection timeout and 600-second total timeout; no retry, alternate data source or analytical fallback is used. The two GEO sources have pinned sizes and SHA256 hashes. Existing unexpected source content stops processing. PBS: 1 CPU, 4 GB, 30 minutes.
2. `geo_oac_bulk_metadata_prep.py`: produce clean clinical metadata, exact sample mapping, the normal-specimen exclusion table, clinical source audit and cohort summaries. PBS: 1 CPU, 4 GB, 30 minutes.
3. `gse_bayesprism_deconvolution.R`: fit the fixed corrected scATLAS reference to all 110 mixtures. PBS: 16 CPUs, 96 GB, six hours; `SCREF_DECONV_CORES` defaults to 16.
4. `gse_malignant_survival.R`: fixed-parent scoring, subgroup survival tests and the three requested survival figures. PBS: 4 CPUs, 24 GB, two hours; `SCREF_SURVIVAL_THREADS` defaults to 4.
5. `gse_malignant_clinical_associations.R`: reuse those malignant scores for descriptive clinical tests and figures. PBS: 1 CPU, 8 GB, one hour.

6. `gse_deconvolution_quality.R`: deterministic three-panel malignant-fraction, posterior-CV and eight-state composition QC from the existing extracted fit. PBS: 1 CPU, 8 GB, 30 minutes; no deconvolution refit.

The pipeline is submitted with PBS success dependencies; each stage must exit successfully and its expected outputs are checked. The R scripts require PBS allocations. Minimal launchers contain environment activation, timestamps, a project-root change and the analytical invocation only.

## BayesPrism reference and inference

The reference is the existing corrected `ref_outs/bulk_malignant_deconvolution/reference/reference_bundle.rds`, produced by `analysis/clinical/Auto_bayesprism_bulk_deconvolution.R`. This shares the implemented scientific method with the OCCAMS/TCGA comparator without rerunning or altering those cohorts. The reference input and epithelial-source manifests are validated in the allocation before inference. Its settings must have version 2 and the independently supported normal-epithelial rule. Reference cells are not reclassified for this analysis.

The source reference uses raw scATLAS RNA counts and upstream malignancy classifications, independent of state-label availability. Nonmalignant epithelial cells require both CNA nonmalignancy and a nonmalignant cluster call. Malignant cells lacking a current state remain malignant state unassigned. Reference counts are summed by cell state. Genes must be detected in at least 20 reference cells, and states require at least 20 reference cells. The fixed reference excludes mitochondrial genes, RPL/RPS ribosomal genes and GENCODE-v19 X/Y symbols. Its gene universe was originally intersected across the reference and canonical OCCAMS/TCGA counts; reusing this fixed reference intentionally preserves that comparator restriction, rather than building a dataset-selected reference.

GSE tumour counts are restricted to shared reference symbols with positive GSE cohort expression. The BayesPrism default bulk-outlier rule removes a gene when its per-sample relative count exceeds 0.01 in more than 0.1 of the 110 samples. This single GSE-specific filter is recorded and used for the GSE fit only; it does not change any existing OCCAMS/TCGA fit. More than 1,000 genes and at least five genes per current MP must remain. An unavailable required reference, stale provenance or failed fit stops immediately.

BayesPrism uses `new.prism(input.type='GEP', key='Malignant')`, the reference type/state labels, and seed 22062026. Automatic outlier filtering is disabled in `new.prism` because it has been applied explicitly. Gibbs controls otherwise match the comparator defaults. Initial cell-state RNA fractions, initial/final cell-type fractions and posterior state coefficient-of-variation values are saved. `get.exp(..., state.or.type='type', cell.name='Malignant')` provides the sample-by-gene malignant-expression matrix. The eight malignant labels are the five current biological states, Hybrid, Unresolved and Malignant state unassigned. Within-malignant fractions divide each initial state contribution by the sum of all eight malignant states. Technical and unassigned states remain in the denominator. Fractions estimate RNA contributions rather than directly counted cell proportions. Only the five biological fractions are clinical/survival features. Deconvolution uncertainty is not propagated into downstream tests.

## Gene sets and scoring

The exact centred refined 17-MP panel is read from the canonical MP genes and grouping table. MP2x, MP11c and MP18a remain excluded. The five biological MP unions use the current configuration, and the five DGE signatures use the first 20 genes per state from `final_state_marker_discovery.R`'s ranked marker table. Thus there are 27 expression features: 17 MPs, five MP unions and five DGE signatures. Adding five within-malignant RNA fractions gives 32 malignant features. MP12 and the stress-adaptive MP union can be identical signatures and must not be interpreted as independent replication.

Original bulk counts and inferred malignant expression use the same shared, nonconstant gene universe. Each matrix is transformed to log2(CPM+1), then scored by Gaussian-kernel GSVA with `min.sz=5`, `mx.diff=TRUE` and `abs.ranking=FALSE`, matching the comparator implementation. A gene is retained only if variable in both complete 110-sample compartments. Every gene-set coverage value and the scoring universe are saved. Both GSVA calls use all 110 parent samples; no scoring is repeated inside treatment strata or after excluding unknown survival status. Clinical scores are exactly reused from the survival cache.

## Overall survival

OS event coding is Deceased=1 and Alive or censored=0. Missing status remains missing even when a follow-up duration exists. Positive duration and explicit 0/1 status are required. All 110 samples are deconvoluted/scored, but only 107 enter OS models: 68 neoadjuvant with 22 deaths, and 39 surgery-only with 24 deaths. The three missing-status patients remain in clinical analyses. No recurrence endpoint is available, so no RFS or endpoint substitution is performed.

Unadjusted Cox proportional-hazards models use Efron ties and a maximum of 50 iterations. Continuous expression scores are scaled by one SD within the endpoint-eligible subgroup; fractions are scaled by 0.1 (ten percentage points). The two compartments use the same endpoint-eligible people. Continuous models require at least 20 subjects and ten deaths and a nonconstant predictor. Feature PH tests use `cox.zph(transform='km')` and remain in the tables; no failed PH test triggers an automatic model change.

The four displays match `02_neoadjuvant_context.pdf`: continuous, median, Q1 versus Q4, and exploratory optimal cutpoint. Median compares greater-than-median versus at-or-below-median. Q1/Q4 retains values at/below the lower quartile or at/above the upper quartile. Optimal cutpoints search exactly 13 quantiles from 0.20 to 0.80 at increments of 0.05 and compare at/above versus below threshold. Binary models require at least 20 retained people, at least five deaths, at least five people in each group, and at least one death per group. Unsupported comparisons receive explicit not-estimated status; no alternative threshold or method replaces them. Cox warnings and nonfinite estimated coefficients stop execution.

For optimal cutpoints, the minimum Wald P is multiplied by 13 (capped at 1) before BH adjustment. All model P values use a fixed 32-feature BH family within cohort, compartment and method, preserving the comparator's conservative family size for the 27 bulk features as well. Selected optimal-cut HRs and confidence intervals do not account for selection and remain exploratory. This correction does not cover comparison of four methods, multiple overlapping subgroup views or later hypothesis selection.

The selected survival PDFs are:

- `01_all_cohort_survival.pdf`: one whole-cohort page per method, all 32 malignant features.
- `02_treatment_group_survival.pdf`: one page per method, surgery-only and neoadjuvant points/intervals together, all 32 malignant features.
- `03_bulk_vs_malignant.pdf`: one continuous-model page with the three cohorts as columns, comparing the same 27 expression features in original bulk and malignant expression, following the comparator `01_bulk_vs_malignant.pdf`.

NS, nominal P<0.05 and BH q<0.05 use open, filled and diamond symbols in the malignant survival figures. Full P/q, intervals, group sizes, support status and searched thresholds remain in tables. Axis-boundary symbols identify intervals beyond the common 0.125–8 HR range. Bulk/malignant effect differences are paired descriptive comparisons, not tests treating them as independent estimates. All-cohort and subgroup analyses are overlapping views, not independent validation cohorts. No causal or prospective response-prediction interpretation is warranted.

## Clinical associations

Sex, age <50 versus ≥50 and broad baseline stage are tested separately in all, surgery-only and neoadjuvant selections. Detailed AJCC substages are retained only as source metadata and are excluded from the clinical test and plot inventory at the user’s request. Broad stage extracts only the recorded Roman-numeral component; no edition or pathologic stage is inferred. The three source records labelled `not possible to stage` remain visible in the cleaned source table, but are missing in broad-stage tests. The user-defined treatment group is compared only in the combined cohort. Age is not converted into exact years or a midpoint. The <50 versus ≥50 split is derived from the original interval endpoints: upper bound <50 defines the younger group, lower bound ≥50 defines the older group; an interval crossing this threshold stops the script. The cohort counts are 9/101 overall, 8/60 neoadjuvant and 1/41 surgery-only. The surgery-only age comparison is not estimable under the existing minimum of three patients per category. Five-year age-band comparisons are excluded. Derived groups and broad stage are exported in `tables/clinical_subject_metadata.csv`; source bands and detailed stage remain available for provenance. OS status and follow-up duration are not reused as baseline explanatory clinical variables.

Mandard grade (1–5) and response groups TRG1–3 versus TRG4–5 are tested **only in neoadjuvant**, as confirmed by the user. Each categorical test retains groups with at least three patients and requires at least two retained groups, matching the clinical comparator. Original counts, exclusions, missing values and applicability are recorded for every cohort/variable. TRG5 has only one patient; this patient remains in the binary response comparison and ordinal test, but not in the five-grade categorical comparison. Two groups use two-sided unpaired Wilcoxon tests (`exact=FALSE` for ties); three or more use Kruskal–Wallis. Constant scores are explicitly not estimable. The statistical unit is one patient, not a cell or gene.

Figure stars use BH within cohort, variable and signature family (17 MPs or five features for each state family). Broader fixed 32-feature q values are also provided. The supplementary ordinal Mandard comparison uses two-sided Spearman correlation with `exact=FALSE` on all 68 neoadjuvant patients, including the single TRG5, with BH within each signature family. This is an exploratory monotonic association, separate from the categorical test. Neither multiplicity scheme controls all variable searches and overlapping cohorts.

Each cohort has an MP PDF and a State PDF, with one eligible clinical variable per page. All 17 MPs and their descriptions stay on one page; State pages have MP-union, DGE and within-malignant percentage rows. Boxplots, jittered patient points, colours, legends with group sizes and FDR stars follow `Auto_malignant_clinical_associations.R`. MP clinical pages use a 14-by-10-inch canvas and 14.5-point axis labels rotated 90 degrees with descriptions wrapped at 24 characters; State clinical pages use 13 by 12 inches. Survival forests use 13 by 14 inches and 13.5-point feature labels kept on one line where possible; the three-column bulk comparison uses 14 by 13 inches. Fonts are adjusted within the comparison page without adding pages solely for text size. No duplicate standalone versions are generated.

## Cache behavior and validation

Every long-running R step fingerprints exact input paths and MD5s plus settings and relevant package versions; survival and clinical caches additionally fingerprint statistical/scoring function bodies. A changed analytical contract stops; `SCREF_FORCE_REBUILD=TRUE` explicitly recomputes that step. `SCREF_REPLOT_ONLY=TRUE` redraws survival or clinical figures only when the matching persistent intermediate exists. Deconvolution does not implement a plot-only mode. Source-download hashes are pinned and unexpected data stop processing. Python metadata outputs are deterministic and refreshed under the user-authorized workflow update. Current reruns write the documented current outputs, never timestamped result folders.

Validation requires: exactly 110 tumour IDs; no normal specimens in fitted/scored matrices; exact 68/42 group membership and 107/68/39 OS counts; source data integrity; raw-count validity; full provenance agreement; finite nonnegative inferred expression; fractions summing to one; exact final 17-MP identities and gene coverage; shared bulk/malignant scoring genes and matched continuous-model patient sets; fixed model counts and multiplicity recalculation; independent representative Cox, categorical rank and ordinal checks; absence of Mandard plots/tests outside neoadjuvant; and all current index links resolving. PDF pages are counted and rendered at final publication width; representative whole-cohort, treatment-group, bulk-comparison and clinical pages are visually inspected. Temporary audits remain outside `analysis/` and never become production dependencies. Compact plotting summaries are written to `updates/new_updates/summaries/`.

## State-composition quality figure

`gse_deconvolution_quality.R` writes `figures/Auto_diagnostics/01_deconvolution_quality.pdf` using the same three-panel design as the shared reference QC figure. Panel a compares initial and updated malignant RNA fractions in 110 biopsies. Panel b shows the median initial cell-state posterior CV with a line ending at the 95th percentile across samples. Panel c stacks the eight within-malignant RNA fractions for every sample, ordered by updated malignant fraction; ties follow extracted sample order. The current state palette is reused, including Unresolved, Hybrid and an explicit grey Malignant state unassigned category. No state or patient is filtered by the plotted abundance or uncertainty.

Exact source fractions, sample ordering, CV summaries and the same descriptive resolution thresholds as the parent workflow are persisted in `tables/state_composition.csv`, `composition_malignant_fractions.csv`, `state_posterior_cv_summary.csv` and `state_fraction_resolution.csv`. The latter reports state fractions below 0.1% and posterior CV above 0.5. These are resolution diagnostics, not validated biological cutoffs. Conditional posterior CV does not capture uncertainty in the reference, and inferred RNA fractions are not measured cell counts. The figure is deterministic from the persistent extracted fit, with no BayesPrism rerun.
