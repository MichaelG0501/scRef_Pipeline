# OCCAMS bulk RNA-seq reconstruction

This directory is the canonical executable record for reconstructing the OCCAMS subject-level raw gene-count matrix. Controlled BAM payloads and the large raw featureCounts table stay under `/rds/general/project/tumourheterogeneity1/ephemeral/OCCAMS/`; persistent source metadata, QC, mappings, and the final matrix are under `ref_outs/OCCAMS/`.

The real EGA credential is deliberately outside this Git repository at `/rds/general/project/tumourheterogeneity1/live/EAC_Ref_all/00_scripts/ega.json` (mode `600`). Both download wrappers reference that exact path. Do not add a credential copy or literal username/password here.

## Run order

1. `occams_download_ega_metadata.sh` downloads the three EGA metadata tables for every accession in `OCCAMS_datasets.txt`.
2. `occams_match_metadata.sh` runs `occams_match_metadata.py` and builds the all-assay matched file manifest.
3. `occams_download_bams.sh` downloads RNA-seq tumour BAM payloads to ephemeral storage.
4. `occams_metadata_coverage_audit.sh` and `occams_bam_reference_audit.sh` verify subject metadata coverage and genome-build consistency.
5. `occams_merge_subject_bams.sh` runs `occams_prepare_subject_bams.py` and creates the 282 subject BAM inputs.
6. `occams_prepare_grch37_reference.sh` downloads/checks GENCODE v19 and tests `chr`, non-`chr`, and mixed-name BAMs.
7. `occams_submit_featurecounts_batches.sh` creates eight size-balanced batches and submits `occams_featurecounts_grch37_batch.sh` as a PBS array.
8. After all eight array elements pass, `occams_combine_featurecount_batches.sh` combines their columns and calls `occams_build_count_matrix.py` to write the canonical live outputs. `occams_featurecounts_grch37.sh` is retained as a validated single-job fallback.
9. `occams_validate_final_outputs.sh` exhaustively validates matrix values, subject/metadata/QC coverage, and the pinned GTF checksum.

All PBS jobs are submitted with `/opt/pbs/bin/qsub`. The detailed implemented method, thresholds, cache behavior, and limitations are in `analysis/methodology/OCCAMS/occams_bulk_rnaseq_reconstruction_methodology.md`.

## Replacement map for the original ephemeral scripts

| Original | Canonical replacement |
|---|---|
| `download_all_occams.sh` | `occams_download_ega_metadata.sh` |
| `EGA` | `occams_download_bams.sh` |
| `match_metadata.py` | `occams_match_metadata.py` |
| `process_rnaseq.py` | `occams_prepare_subject_bams.py` |
| `merge_bams.sh` | `occams_merge_subject_bams.sh` |
| `run_featurecounts.sh` | size-balanced `occams_featurecounts_grch37_batch.sh` plus `occams_combine_featurecount_batches.sh`; `occams_featurecounts_grch37.sh` is the single-job fallback |
| `build_count_matrix.py` | `occams_build_count_matrix.py` |
| `ega_metadata_files/check_missing.py`, `count_subjects.py` | `occams_metadata_coverage_audit.py` |
| generated `merge_commands.sh` | regenerated by `occams_prepare_subject_bams.py`; historical copy retained under `ref_outs/OCCAMS/logs/historical/` |

The original `download_all_occams.sh` is not copied because it embeds a live password. Its functionality is fully replaced by the credential-safe wrapper. Historical PBS and pyega3 logs are retained in the gitignored live output tree.

## Current-data warning

Do not use the historical ephemeral `counts/OCCAMS_RNAseq_raw_counts.txt`: it was generated with a GRCh38 GTF against GRCh37 BAMs. The corrected reconstructable cache is `counts/OCCAMS_RNAseq_GRCh37_raw_counts.txt`; the downstream canonical matrix is `ref_outs/OCCAMS/counts/OCCAMS_RNAseq_GRCh37_gene_counts.tsv.gz`.

The complete 282-subject matrix retains one explicit QC outlier, subject `90687ad9d09f7677ab6fc83f75b78bd3fed8a9934e071f071306007c79277dab` (EGAF00001809022). Use `ref_outs/OCCAMS/tables/OCCAMS_RNAseq_GRCh37_sample_qc_summary.csv` for documented sensitivity filtering; do not silently remove it from the source matrix.
